## Instructions

### Compile

```
   mvn clean package
```

### Start the web server
```
```shell
java -jar target/springai-multiagent-1.0-exec.jar
````

### Swagger UI
```
http://localhost:8080/swagger-ui/index.html
```

### Load the data

```shell
java -jar target/multiagent-dataloader.jar
```


### Test
```shell
java -jar target/multiagent-cli.jar
```
